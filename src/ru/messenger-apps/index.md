# Приложения в мессенджере — обзор

**Messenger Apps** позволяют подключить внешнее веб‑приложение к комнате чата Korfix (личной
переписке или группе). Приложение открывается во встроенном перемещаемом окне прямо внутри чата,
получает подписанную личность открывшего его пользователя и может вернуть результат обратно в
переписку — сообщением.

Если вы уже делали **Telegram Mini App**, всё покажется знакомым — существующее Telegram‑приложение
переносится с минимальными правками (см. [Адаптация Telegram‑приложения](telegram-compat.md)).

---

## Как это работает

- Приложение — это просто **URL** плюс несколько настроек, привязанных к комнате.
- Когда приложение настроено, слева от поля ввода появляется **иконка приложения**. Тап по ней
  открывает приложение.
- Приложение подключает небольшой **SDK Korfix Web App** и получает личность открывшего его
  пользователя через подписанную строку `initData` (передаётся в hash‑части URL — ровно как у Telegram
  Mini Apps в браузере).
- Приложение общается с чатом через мост `postMessage`, доступный как `window.KorfixApp`: показать
  главную кнопку, открыть диалоги и, главное, — **`sendData()`**, который превращает данные приложения
  в сообщение чата и закрывает окно.

```
[ комната чата ] --(иконка)--> [ окно приложения (iframe) ]
        ^                                  |
        |          sendData(данные)        v
    сообщение  <----------------  мост KorfixApp
```

---

## Для пользователей

Откройте чат, нажмите кнопку **ℹ️ информация** в шапке → вкладка **Apps** → добавьте приложение
(название + URL). В **групповых** чатах приложениями управляют владельцы/админы; в **личных** — любой
из участников. Как только есть хотя бы одно приложение, **иконка приложения** появляется у поля ввода
для всех участников комнаты.

Приложения открываются **плавающим окном**, которое можно перетаскивать и менять в размере, или в
**новой вкладке браузера** — это настраивается для каждого приложения.

!!! note "Два вида приложений Korfix — не путать"
    **Messenger Apps** (этот раздел) живут внутри комнат чата и используют `window.KorfixApp`.
    **Миниапы маркетплейса** (раздел [Миниапы](../miniapps/index.md)) встраиваются в каталоги ERP и
    используют `VMCRMUserApp`. Разная поверхность, разный SDK, разная авторизация.
