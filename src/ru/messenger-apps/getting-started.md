# Первое приложение в мессенджере

Messenger App — это любая веб‑страница, которая подключает SDK Korfix Web App и открывается внутри
комнаты чата.

> **← [Обзор](index.md)** · далее: [SDK и авторизация](sdk.md)

---

## 1. Подключите SDK

```html
<script src="https://ВАШ-KORFIX-ХОСТ/templates/def/chat/korfix-web-app.js"></script>
```

`ВАШ-KORFIX-ХОСТ` — хост, где работает мессенджер (например `panel.korfix.ru` или `vibe.korfix.app`).
SDK — крошечный файл без зависимостей. Если приложение должно работать на нескольких инстансах Korfix,
можно **вендорить** (положить копию) `korfix-web-app.js` рядом с приложением — в нём нет привязки к
хосту.

SDK создаёт глобальный объект: **`window.KorfixApp`**.

---

## 2. Сообщите о готовности и прочитайте пользователя

```html
<script src="https://ВАШ-KORFIX-ХОСТ/templates/def/chat/korfix-web-app.js"></script>
<script>
  KorfixApp.ready();          // сообщить хосту, что приложение готово
  KorfixApp.expand();         // (опц.) запросить больше высоты

  const user = KorfixApp.initDataUnsafe.user;   // { id, first_name, username, ... }
  document.body.append('Привет, ' + (user ? user.first_name : 'гость'));
</script>
```

!!! warning "`initDataUnsafe` нельзя доверять"
    Любое значимое действие (сохранение данных, выдача доступа) должно проверять **подписанную**
    `KorfixApp.initData` на бэкенде. См. [SDK и авторизация](sdk.md).

---

## 3. Добавьте главную кнопку и верните результат

```html
<script src="https://ВАШ-KORFIX-ХОСТ/templates/def/chat/korfix-web-app.js"></script>
<script>
  KorfixApp.ready();
  KorfixApp.MainButton.setText('Отправить в чат').show().onClick(function () {
    KorfixApp.sendData(JSON.stringify({ picked: 42 }));
  });
</script>
```

`sendData()` публикует данные в комнату как сообщение (до 4096 байт) и закрывает окно приложения. Это
естественный мост «приложение → чат».

---

## 4. Зарегистрируйте приложение в комнате

1. Откройте чат, нажмите кнопку **ℹ️ информация** в шапке.
2. Перейдите на вкладку **Apps**.
3. Заполните **название**, **URL**, **тип открытия** и необязательный **секрет** (см. ниже) → **Сохранить**.

Права: **группа** — владельцы/админы; **личный** чат — любой из участников.

### Тип открытия

| Тип | Поведение |
|-----|-----------|
| `popup` (по умолчанию) | Плавающее окно внутри страницы — двигается за заголовок, тянется за угол. |
| `newtab` | Открывается в новой вкладке браузера. |

### Секрет

Если приложение проверяет пользователя на **бэкенде**, задайте **секрет** при регистрации. Korfix
подписывает `initData` этим секретом по стандартной, совместимой с Telegram схеме, а ваш бэкенд
проверяет тем же секретом. Оставьте поле пустым для доверенных внутренних страниц без проверки —
тогда приложение откроется без `initData`.

---

## Чеклист

- [ ] SDK подключён с хоста Korfix (или вендорен)
- [ ] Вызван `KorfixApp.ready()`
- [ ] Бэкенд проверяет `KorfixApp.initData`, если вы доверяете личности пользователя
- [ ] Приложение зарегистрировано в комнате с секретом (если есть backend‑проверка)
- [ ] `sendData()` используется там, где приложение должно вернуть результат в чат
