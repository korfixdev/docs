# Quick Start — вайбкодинг на Korfix за 10 минут

> **См. также:** [miniapps/getting-started.md](miniapps/getting-started.md) · [miniapps/rules.md](miniapps/rules.md) · [plugin-update.md](plugin-update.md)
> **← [Home](index.md)**

Это стартовая страница для тех, кто слышал про Korfix и про вайбкодинг, и хочет попробовать сам. К концу — у тебя зарегистрированный аккаунт, установленный плагин, рабочий API-токен и понимание, что писать Claude, чтобы он собрал тебе приложение.

Платформа Korfix — место, где живут твои данные (каталоги), инструменты поверх них (миниаппы) и AI с прямым доступом к этому всему (MCP). Вайбкодинг здесь — это когда ты описываешь нужное приложение словами, а AI собирает его целиком, разворачивает базу данных и публикует в маркетплейс. Без DevOps, без сервера, без гайдов по UI.

## Шаг 1. Регистрация — 1 минута

Открой [vibe.korfix.info](https://vibe.korfix.info), введи почту, подтверди. Карта не нужна, пробного периода нет — для пользователя платформа бесплатна.

После входа ты попадаешь **не на пустой дашборд**. В аккаунте уже стоит набор предустановленных миниаппов — Roadmap, Канбан-доска, Финансы, Prompt Library, n8n Monitor, Games Hub и другие. Дашборд с виджетами тоже на месте. Всё это собрано тем же путём, который ты сейчас пройдёшь — описанием через AI. Это твой первый ответ на вопрос «что вообще можно сделать на этой платформе».

Покрути меню, открой пару приложений, посмотри, что в каталогах. Дальше — твои собственные.

## Шаг 2. Установи плагин korfix-devkit

`korfix-devkit` — плагин для Claude Code, который превращает Claude в разработчика миниаппов: знает форматы платформы, проектирует решение, пишет код, валидирует и деплоит.

Команды установки — на [главной странице документации](index.md): добавить маркетплейс `korfixdev/marketplace`, поставить `korfix-devkit`, перезагрузить плагины. Дальше — [обновления](plugin-update.md) по мере выхода версий.

Плагин приносит с собой агентов (`korfix-analyst`, `korfix-miniapp-dev`, `korfix-miniapp-validator`), скиллы и документацию платформы.

**Без Claude Code тоже можно.** Если ты в Cursor, Codex или другом AI — просто скажи модели прочитать [docs.korfix.info](https://docs.korfix.info). Качество ниже (нет агентов и автоматической валидации), но рабочее.

## Шаг 3. Создай API-токен

Токен нужен, чтобы AI мог публиковать приложения в твой маркетплейс и работать с твоими данными.

В платформе: **Settings → API** (или вбей `api` в поиске меню слева — это самый быстрый способ найти раздел). Нажми **Add**.

В форме укажи:

- **Назначение** — например, «vibe coding» (это просто метка для тебя).
- **Каталоги и методы** — права токена.

### Какие права давать токену

| Каталог | Зачем нужен | Уровень |
|---------|-------------|---------|
| `marketplace` | публикация и обновление миниаппов через API | **обязательно** (read + write) |
| `custom_dbtables` | создание собственных каталогов из инсталлера миниаппа | **рекомендуем** (read + write) |
| `custom_dbfields` | создание полей в собственных каталогах | **рекомендуем** (read + write) |
| `installed_apps` | работа с реестром установленных приложений | по желанию |
| Бизнес-каталоги (`ag_*`, `tt_*`, `b2b_*`, `md_*` и др.) | если AI должен работать с конкретными бизнес-данными | пропускай, если делаешь личные приложения |

**Минимум для деплоя своих приложений** — `marketplace` на запись. Без него агент не сможет загрузить zip.

**Минимум для self-provisioning** (когда приложение само создаёт свои каталоги при установке) — добавь `custom_dbtables` и `custom_dbfields` на запись. Это нужно почти любому полезному миниаппу со своими данными.

Если сомневаешься — выдай галочку «все права» и сужай позже, когда поймёшь, что именно тебе нужно. Токен в любой момент можно отозвать или пересоздать.

После сохранения токен останется в твоей панели — копировать никуда и хранить в файлах его не нужно. Достаточно, что он существует и активен.

## Шаг 4. Передай токен Claude — без копипасты

Не клади токен в env-переменные, конфиги, скрипты и чаты. Просто запусти Claude Code и попроси что-то опубликовать. Агент `korfix-miniapp-dev` сам спросит, какой инстанс и какой токен использовать, и без подтверждённых значений деплоить не пойдёт.

Один раз вводишь — дальше плагин работает с этим токеном до конца сессии.

## Шаг 5. Первый промпт

Ты готов. Скажи Claude словами, какое приложение хочешь:

> Нужно приложение для Korfix: учёт расходов. Я завожу кошельки и статьи трат, веду транзакции. Виджет на дашборд — круговая диаграмма по статьям и список последних транзакций.

Что произойдёт:

1. **`korfix-analyst`** задаст уточняющие вопросы — про переводы между кошельками, валюту, период диаграммы по умолчанию. Отвечай словами.
2. **`korfix-miniapp-dev`** соберёт приложение: `config.json`, инсталлер с нужными каталогами и связями, виджет дашборда. Упакует в zip.
3. **`korfix-miniapp-validator`** проверит код по релиз-чеклисту (свежий контекст, независимо).
4. После твоего подтверждения — деплой в твой маркетплейс по токену из шага 4.

В маркетплейсе появляется новое приложение. Ставишь — инсталлер сам разворачивает каталоги «Кошельки», «Статьи расходов», «Транзакции» с правильной схемой, на дашборде появляется виджет. Открываешь и пользуешься.

Если что-то не так — той же фразой: «добавь фильтр по месяцу», «убери виджет последних транзакций, оставь диаграмму». AI правит и перевыкладывает.

## Бонус. AI читает данные напрямую через MCP

Это отдельная история, перпендикулярная вайбкодингу. Если ты хочешь, чтобы **Claude Desktop, Cursor или n8n** видели твои каталоги напрямую и могли спрашивать «сколько ушло на еду» — используй **MCP-URL** из шага 3.

В `claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "korfix": {
      "type": "sse",
      "url": "ВСТАВЬ_MCP_URL_ИЗ_НАСТРОЕК"
    }
  }
}
```

Перезапускаешь Claude Desktop — он видит твои каталоги. Сборка приложений через `korfix-devkit` и чтение данных через MCP — два независимых сценария, можно использовать оба сразу.
